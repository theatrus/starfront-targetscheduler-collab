# Starfront TargetScheduler Collab 0.1.4.0

- Add **Fetch tonight** to the Advanced Sequencer. Place it after equipment
  connects and before Target Scheduler to fetch and apply assignments using
  the current rig profile. It waits for Apply to finish, works in Hello or
  Collab mode, and defaults to aborting the sequence on failure.

Use **Connect Equipment → Fetch tonight → Target Scheduler**. The instruction
applies assignments even when **Apply automatically** is off. Connect the
rotator before the fetch so Starfront receives its current capabilities.
