# 0.1.1.0

- The default server is now `https://collab.starfront.space`. A saved
  setting with the old address moves to the new one, and so does its saved
  token. Sign-in failed on the old address because the server sends sign-in
  links for its new name.
- Once this telescope is registered, the page says so and hides the token
  field and the sign-in button. Sign in with Discord registers the telescope
  and saves its token; paste a token only if the server's owner gave you one.
- In Hello mode, the share and collaboration lists say they show in Collab
  mode, and the Target Scheduler settings say Hello mode does not use them.
- If a server's sign-in link names another address, the message says which
  address to use.
