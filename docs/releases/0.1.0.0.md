# 0.1.0.0

First release. Built for the Starfront app and collaboration server,
N.I.N.A. 3.2 or later, Target Scheduler 5 and the AstroCollab API spec.

- **Hello mode** reports the mount position (J2000), rig state, target name
  and telescope name. It checks in every 5 minutes and soon after each slew.
  You can keep the position or target name private. On exit, the telescope
  leaves the other rigs' charts.
- **Collab mode** pulls tonight's assigned panels into Target Scheduler as a
  project, targets and exposure plans. Review the changes and click Apply, or
  turn on automatic apply. Panels not assigned tonight are paused, never
  deleted.
- Server filters (H, O, S, R, G, B, L) match your filter names, such as Ha,
  OIII, SII, Red and Lum. Existing exposure templates are reused; when several
  match, the longest default exposure wins.
- Accepted frames are reported per panel, filter and night, with HFR, guide
  RMS and Moon figures. The server's verdict is shown on the page.
- Join open collaborations, and accept or decline offered shares, from the
  plugin page.
- Sign in with Discord or paste a telescope token. Tokens live in Windows
  Credential Manager.
